# Blockchain Glossary

## Blockchain
A distributed ledger that records transactions across multiple computers.

## Layer 2
A scaling solution built on top of a base blockchain to improve speed and reduce costs.

## Smart Contract
A self-executing program stored on a blockchain.

## EVM
The execution environment for Ethereum smart contracts.

## Reentrancy
A vulnerability where a contract is repeatedly called before its state is updated.

## Overflow
When a number exceeds its maximum storage capacity.
